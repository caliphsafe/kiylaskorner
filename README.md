# Kiyla's Korner — 43 Build V6

## What changed
- Removed all food imagery from the menu.
- Menu is now a text-first ordering interface closer to the No Problemo ordering logic, but styled entirely within Kiyla's dark/colorful visual system.
- Preserved the real source category names.
- Most Ordered comes first, then food categories, then shakes/dessert/drinks.
- No standalone Build Your Own section. Build Your Own Burger, Build Your Own Wrap, and Build Your Own Dogs live in their respective real menu categories.
- Added a dedicated space section using Kiyla's public restaurant-gallery imagery, visually cropped so each tile shows one space photo rather than a collage.
- Retained the user's supplied Kiyla's Korner photo as the primary brand image.

## Ordering
The local cart is a front-end ordering UX. Final checkout hands off to Kiyla's current online ordering provider until a direct merchant payment/order API is connected.

## Deploy
Upload the contents of this folder directly to the GitHub repository root:
- index.html
- styles.css
- app.js
- robots.txt
- sitemap.xml
- assets/

No package-lock.json is included.
